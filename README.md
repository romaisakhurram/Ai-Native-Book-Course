# AI-Native Book Course: Physical AI & Humanoid Robotics

This repository hosts the content for the "AI-Native Book Course: Physical AI & Humanoid Robotics". The project aims to provide technically accurate and clearly explained content for intermediate learners across AI, robotics, and simulation.

## Key Aspects:
- **Technical Accuracy:** Covers ROS 2, Gazebo, Unity, NVIDIA Isaac, Whisper, VSLAM, Nav2, and RAG systems.
- **Clear Explanations:** Designed for intermediate learners, making complex topics accessible.
- **Reproducibility:** All code and configuration examples are runnable, allowing readers to reproduce book generation, deployment, chatbot setup, and the final capstone humanoid simulation.
- **Consistent Structure:** Adheres to a consistent structure aligned with Spec-Kit Plus and Claude Code workflows, with chapters aligning to four modules and a final capstone.
- **Format & Deployment:** A Docusaurus book generated with Spec-Kit Plus, deployed on GitHub Pages with an embedded RAG chatbot.
- **Chatbot Scope:** Chatbot responses are strictly based on book content.
- **Coverage:** Includes four modules and a reproducible capstone walkthrough.
