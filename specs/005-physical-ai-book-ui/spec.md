# Physical AI & Humanoid Robotics Book Website UI Specification

## Overview
Design a professional academic book UI using Docusaurus for a multi-module course book targeting university students, researchers, and professionals studying AI, Robotics, and Embodied Intelligence.

## Target Audience
- University students
- Researchers
- Professionals studying AI, Robotics, and Embodied Intelligence

## Success Criteria
1. Homepage hero uses provided humanoid/AI image as full-width background behind heading
2. Dark professional color theme suitable for technical book
3. Clear navigation for multi-module course book
4. Sidebar structured for modules and chapters
5. Typography optimized for long-form technical reading

## Constraints
- Framework: Docusaurus (latest stable)
- Styling: Custom CSS / theme overrides only
- Color palette: Dark navy/charcoal background, blue-cyan accents
- Layout: Desktop-first, responsive
- Accessibility: High contrast, readable fonts

## UI Requirements

### Hero Section
- Full-width background image with humanoid/AI imagery
- Gradient overlay over background image
- Course title, subtitle, and CTA buttons visible on image
- Text should maintain readability against any background image

### Navigation
- Sticky navbar at the top of the page
- Left documentation sidebar that remains visible
- Modules and chapters organized hierarchically in sidebar
- Clear, intuitive navigation between different sections of the book

### Typography
- Optimized for long-form technical reading
- High contrast for accessibility
- Professional, readable font selections

### Code Blocks
- Styled specifically for Python, YAML, and Bash syntax highlighting
- Distinct visual presentation from regular text
- Copy functionality for code snippets

### Styling
- Dark theme with navy/charcoal backgrounds
- Blue-cyan accent colors for highlights and links
- Minimal animations (hover and fade only)
- Consistent styling throughout all pages

## Technical Requirements
- Built with Docusaurus framework
- Custom CSS overrides for theme customization
- Responsive design for various screen sizes
- Mobile-friendly navigation when screen space is limited

## Not Included in Scope
- Marketing landing pages
- E-commerce or payment flows
- Blog or community forum
- User dashboards or authentication logic

## Acceptance Criteria
- [ ] Homepage displays hero section with background image and readable text
- [ ] Dark theme applied consistently throughout the site
- [ ] Navigation enables easy movement between modules and chapters
- [ ] Code blocks properly formatted for Python, YAML, and Bash
- [ ] Site is responsive on different device sizes
- [ ] Accessibility standards met with sufficient contrast
- [ ] Typography optimized for technical reading
